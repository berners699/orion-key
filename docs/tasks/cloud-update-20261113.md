1. 核对 Git 差异和远程提交，排除凭据、数据备份与镜像归档。
2. 本机执行 TypeScript 检查并构建 linux/amd64 前端镜像。
3. 制作仅含前端镜像与更新脚本的增量包；检查脚本、校验和及隔离容器 HTTP。
4. 提交推送新增文件至现有 GitHub 仓库。
5. 负责人通过面板上传增量包后，更新脚本核对内存、保存旧镜像并仅替换 web；健康或 HTTP 检查失败则尝试回滚。
6. 核对公网首页、商品接口、调试文字移除、现有订单与支付配置。

不执行数据迁移，不更新 API/数据库/支付网关或服务器部署配置。回滚使用发布前前端镜像，不回滚业务数据。
